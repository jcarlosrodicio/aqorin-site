# Security

This repository is a static site: the landing page, and the documentation under
`/docs`, built with Astro Starlight from `docs-site/`. It holds no credentials and
runs no server code; the documentation's npm dependencies are used only to build it.

To report a security issue, use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on this repository. Please do not open a
public issue for it.
