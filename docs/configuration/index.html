Configuration

Aqorin writes only its own files. It never writes your runtimes’ configuration. Everything below is written by the TUI or the CLI through one writer that keeps your comments and key order. You can also edit the files by hand.

In a project: .aqorin/

Section titled “In a project: .aqorin/”
Path Holds
.aqorin/aqorin.yaml The project’s configuration (below).
.aqorin/agents/<id>.agent.yaml Your agents.
.aqorin/workflows/<id>.workflow.yaml Your workflows.
.aqorin/assignments/<name>.profile.yaml Where each step runs: assignments.
.aqorin/tasks/ Tasks with their checks, written by New task.
.aqorin/skills/<id>/ Pinned copies of your skills.
.aqorin/mcp/<id>.mcp.yaml Your MCP servers, credentials by reference only.

aqorin init (or Home’s checklist) creates .aqorin/. Directories are created 0700 and files 0600.

Global

Section titled “Global”
macOS
Configuration ~/Library/Application Support/aqorin/config.yaml
Runs and evidence ~/Library/Application Support/aqorin/data/
Cache ~/Library/Caches/aqorin/

The global configuration holds:

  • the global default runtime (aqorin use <runtime> --global);
  • your chosen installations, each held by its path and the SHA-256 of its bytes;
  • your connections;
  • your OpenCode provider key references (Credentials).

The project’s configuration always wins over the global one.

Environment variables

Section titled “Environment variables”
Variable Effect
AQORIN_CONFIG_HOME Where the global configuration lives.
AQORIN_DATA_HOME Where Runs and evidence live.
AQORIN_CACHE_HOME Where the cache lives.
NO_COLOR No colour.
AQORIN_TUI_ASCII=1 ASCII glyphs only.
AQORIN_TUI_MOTION=0 No motion in the status bar.
AQORIN_TUI_BELL=0 No bell when something starts waiting for you.

Aqorin refuses to write through a symlinked AQORIN_CONFIG_HOME or AQORIN_DATA_HOME.
